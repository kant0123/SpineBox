## 全体像

- [[overview]] — システム全体像と各ページへの入口

## Components — モジュール・機能単位 (`components/`)

- [[archive-reading]] — アーカイブの目次読みと 1 エントリの読み出し。zip の名前の復号順(UTF-8 フラグ → 0x7075 → cp932)、7-Zip CLI での 7z / rar の読み方と異常系、危険なエントリ名と展開上限
- [[backend]] — FastAPI のバックエンド(設定・DB・スキャン・閲覧 API)。フロントと共有する API 契約と、蔵書レコードを消さない offline / missing の扱い
- [[frontend]] — 蔵書一覧と右綴じ・見開きリーダーのブラウザ側(frontend/)。見開き計算の規則、読書位置の保存の仕方、読み込み待ち・取得失敗の表示、モック API、CI への組み込み
- [[metadata-clients]] — 公開 DB クライアント(spinebox/metadata/)の入口。検索の入出力の型、失敗の表現、生応答の保存(metadata_responses)、取得元ごとのレート制限、確からしさの出し方、後続の結線が使う入口。DB の作品・巻へは結線しない
- [[novel-reader]] — 小説(EPUB・テキスト)の巻と縦書きリーダー。EPUB の HTML を信用しない 3 段の安全方針(サーバーの許可リスト・ブラウザの作り直し・CSP)、文字コード判定と分割、行の途中で切らないページ割り、区切り+割合の読書位置、却下した代替案
- [[organize]] — 整理処理(1 ソース → 巻ごとの CBZ)。蔵書に書き込む唯一の経路。作業場で作って全巻検証 → 改名で確定 → 元を退避、のジャーナルつき往復と元に戻す。安全設計の理由と却下した案

## Concepts — 横断的な仕組み・設計判断 (`concepts/`)

- [[duplicate-detection]] — 別スキャンの重複候補の検出。全ページの dHash の集合と巻番号の候補で判定し、自動では消さない。しきい値の根拠(実データの距離の分布)、全ページを指紋にした理由、却下の持ち方、計算の範囲
- [[extraction-cache]] — 内側アーカイブだけを開いたときにハッシュ名で取り出す展開キャッシュ。容量上限つき LRU、使用中は消さない、スキャンでは使わない
- [[metadata-sources]] — 公開 DB 3 つ(国立国会図書館サーチ・AniList・MangaUpdates)の癖・制限・利用条件・採否の理由と、実通信で確かめた応答の違い、既定のレート制限の根拠
- [[recurring-review-findings]] — レビューで妥当と判定された指摘を誤りの種類ごとに集約した台帳。着手時と push 前に読む
- [[volume-split]] — 内側アーカイブを開いて中の巻の単位を子の巻として登録する「巻への分解」と、名前の巻範囲と中身の食い違いの検出。巻番号の候補の読み方・保存場所、読書位置の引き継ぎ、重複を食い違いにしない理由
- [[work-grouping]] — 作品の名寄せ(フェーズ 3)。巻の名前から作品を派生させ、別名・著者・統合の根拠を項目ごとの出所・手動フラグ・確信度つきで持つ。自動統合の基準、手動の決定を守る規則、欠け巻の数え方、却下・分けた組を戻さない理由

## Operations — 運用手順・障害対応 (`operations/`)

- [[local-ci]] — Actions が課金・上限でジョブを起動しないとき、CI を手元で回して結果を commit status で PR に載せる手順と、代替を認める条件
- [[server-setup]] — サーバー機(Windows)での初回セットアップ、タスクスケジューラへの常駐登録、LAN 公開(ファイアウォール)、更新手順、python を孤児にしない仕組み、ログの場所。開発機で確かめた範囲とサーバー機での確認待ちの範囲

## 未作成ページ (リンクだけ存在する / これから書く)

2 つの役割を兼ねる節。

1. 他ページから `[[...]]` で参照されているが実体が無いページの控え。次に書くべきページの候補リスト
2. **これから作るページ名の予約。** 複数セッションが同時に走る場合、実体を書く前にここへ名前を
   控えておかないと、同じ概念のページが別名で二重に作られる。着手時にこの節を読み、
   予約済みの名前と衝突していないか確認する

実体を作ったらこの節から消す(消し忘れは lint が落とす)。
