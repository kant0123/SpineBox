# メタデータの取得元(公開 DB)の癖と制限

GOAL.md「メタデータの取得元」の方針(国立国会図書館サーチが巻ごとの書誌の主力、AniList / MangaUpdates が作品単位のタグ・あらすじ・ローマ字名、楽天ブックスは今は使わない)を
#44 で実装するときに、実通信(2026-11-02)と公開ドキュメントで確かめたこと。クライアントの構造は [[metadata-clients]]。
**取得元の仕様は予告なく変わる**ので、ここの数字は「いつ確かめたか」込みで読む。食い違いを見つけたらコードの挙動が正でここを直す。

## 国立国会図書館サーチ API(`ndl`)— 巻ごとの書誌

| 項目 | 内容 |
| --- | --- |
| 使うもの | OpenSearch `https://ndlsearch.ndl.go.jp/api/opensearch`(RSS 2.0 の拡張)。`title` / `creator` / `isbn` / `mediatype=books` / `cnt`(上限 500、501 件目以降は取れない) |
| キー・料金 | 不要。**非営利で対価を得ないなら申請不要**(広告収入・対価があれば申請)。継続的に使うなら API 利用申請フォームでの連絡が求められている(承認は不要)。**このアプリは個人・非営利の利用なので、継続利用の申請はしない(2026-11-02 利用者判断、#45)**。広告・対価を伴う使い方に変えるときは判断し直す |
| 表示義務 | アプリ・サイトは NDL サーチ API を利用していることを明示する。**実装済み(#50)**: 作品の一覧と作品ページの末尾に、有効な取得元の名前・サイトへのリンク・「NDL サーチ API」などの API 名を出す(`frontend/src/works/Credits.tsx:6 Credits()`)。候補・連携済みの項目には出典 URL のリンクがある |
| 制限 | 数値は公開されていない。**同時リクエスト数に制限**があり、高負荷が続くとサーバーごと遮断されうる。並列に送らない |
| 既定の間隔 | 1.0 秒(直列。数値の根拠は無く、同時要求を避けて人が検索する速さに収めた値) |
| 応答 | UTF-8、`text/xml`。1 件 ≒ 3 KB |

**SRU(`/api/sru`、`recordSchema=dcndl`)でなく OpenSearch にした理由。** 同じ作品名で両方を引いて比べた。OpenSearch の `item` は巻次(`dcndl:volume`)・シリーズ名(`dcndl:seriesTitle`)・
出版者・発行年月(`dcterms:issued`)・ISBN・著者(姓, 名)と読み・ジャンル(`dcndl:genre` = 漫画)・NDC を既に持つ。SRU の dcndl は 1 件が約 14 KB の RDF/XML で、
増えるのは別タイトル(パラレルタイトル = 英題)と所蔵情報(`dcndl:Item`、使わない)程度。パース・転送量・実装の分かりやすさで OpenSearch を採った。
英題が要るようになったら SRU の `dcndl:alternative` を足す手がある(AniList / MangaUpdates からも別名は取れるので今は要らない)。

癖:

- **同じ作品名で漫画版と小説版が別の巻として混ざって返る**(「お気楽領主の楽しい領地防衛」は ガルドコミックス版 と OVERLAP NOVELS 版)。`kind` はジャンル・NDC(726.1 漫画 / 913 小説)・シリーズ名から推す。
  判断できなければ None(決めつけない)
- **作品名だけで引くと別の本が大量に混ざる**(「かくかくしかじか」は詩集・CD ブック・映画ノベライズが先頭)。`creator` を付けると東村アキコの 1〜5 巻だけに絞れる(表記は `東村アキコ` でも `東村 アキコ` でも可)。
  クライアントは著者があれば `creator` で引き、**0 件なら著者なしで引き直す**(著者の表記が NDL と合わない場合のため)
- 著者は `東村, アキコ, 1975-` のように**生没年が付く**ことがある。`赤池, 宗` は姓名の連結に直す(欧文は `John Smith`)
- 巻次は文字列(`1` `上` `1-2`)。数字だけのとき `volume` に数値を入れ、元の表記は `volume_label` に残す
- 作品名は `作品名 : 副題`。主題と副題を分けて持つ(題名の比較は主題で行う)
- **ローマ字の検索語でも日本語の項目が当たる**(読みで引いているらしい)。項目の読み(カタカナ)をローマ字にして題名と比べるため、確からしさは出せる(`spinebox/metadata/kana.py:40 to_romaji`)
- **内容紹介(あらすじ)は無い。** `dc:description` は「奥付のタイトル: …」「出版」「展覧会カタログ」のような書誌の注記と年で、あらすじではない(記録済みの 4 検索で確認、#74)。日本語のあらすじの取得元にはならない
- `dc:date` / `dcterms:issued` は発行の年月。RSS の `pubDate` は書誌レコードの更新日で、発売日ではない(使わない)

## AniList(`anilist`)— 作品単位のタグ・あらすじ・ローマ字名

| 項目 | 内容 |
| --- | --- |
| 使うもの | GraphQL `POST https://graphql.anilist.co`。`media(search:, type: MANGA)`(`format` が NOVEL なら小説) |
| キー・料金 | 不要(読み取りのみ)。非営利は無料(月収益 $150 未満の商用も無償) |
| 制限 | **公式ドキュメントは 90 回/分、ただし現在は障害対応で 30 回/分に下がっていると明記**(2026-11-02 時点)。超えると 1 分間の停止、429 と `Retry-After` / `X-RateLimit-Reset` |
| 既定の間隔 | 2.0 秒(= 30 回/分。落とせないので障害時の値に合わせた) |
| 利用条件 | **API をバックアップ・データ置き場として使うこと、大量収集は禁止。** 同種の漫画リスト・トラッカーサービスでの利用も不可(SpineBox は蔵書閲覧で該当しない) |

癖:

- 日本語の作品名でよく当たる。**ローマ字は綴りが厳密**: `Okiraku ryoshu no tanoshi ryochi`(長音を省いた綴り)は 0 件、AniList の綴りは `Okiraku Ryoushu no Tanoshii Ryouchi Bouei`。0 件は失敗ではなく成功した 0 件
- 漫画版と小説版が別の項目になる(同じ作品でも `format` で分かれる)。`total_volumes` は連載中は null
- **GraphQL のエラーは HTTP 200 で `errors` に入って返る**ことがある。`data` が空なら ParseError として失敗にする(取得失敗の結果になる)
- 利用条件のため、保存した応答は**有効期限つきの使い回し**(既定 30 日)にとどめ、永続的な写しにしない。テスト用の記録(`tests/fixtures/metadata/anilist/`)は検索 3 件分だけ
- タグは `rank`(0〜100)つき。スポイラー(`isMediaSpoiler` / `isGeneralSpoiler`)と rank 40 未満は取り込まない。言語は英語(ジャンル・タグ・あらすじとも。日本語にするのは反映側: [[metadata-linking]] の「日本語での表示」)

## MangaUpdates(`mangaupdates`)— ジャンル・タグ・別名(日本語名を含む)・原版元

| 項目 | 内容 |
| --- | --- |
| 使うもの | `POST https://api.mangaupdates.com/v1/series/search`(body: `search` `perpage`)と `GET /v1/series/{series_id}` |
| キー・料金 | 読み取りは不要(ログインしない) |
| 制限 | **公式ドキュメント(`https://api.mangaupdates.com/` の redoc)に数値が見当たらず、応答のヘッダにも制限の値は無い**(2026-11-02 に確認、未確認のまま)。429 が来ればレート制限として扱い、`Retry-After` を守る |
| 既定の間隔 | 1.0 秒(根拠となる公称値が無いので、NDL と同じ控えめな値) |

癖:

- **`perpage` は 10 未満を指定しても無視され 25 件返る**(3 と 8 で確認、10・50 は効く)。クライアントは 10 以上で引いて先頭から切る
- 検索の結果には別名・著者・出版社が無い。**`associated`(別名。日本語名・各国語)・`authors`・`publishers`・`categories` は詳細にだけある**。そのため上位の候補だけ詳細を引き直す
  (数は設定 `detail_limit`、既定 3)。**詳細を引く候補は MangaUpdates の並びでなく、検索結果の項目で見た確からしさの高い順に選ぶ**
  (ローマ字で検索すると、本命が MangaUpdates の並びの 4 位以降に来ることがあり、先頭 3 件では取りこぼした)
- 検索結果の `hit_title` は、**当たった別名**(日本語名でも当たる)。正式名(`title`)は日本の作品ではローマ字が多い。日本語の別名があればそれを作品名にし、正式名はローマ字名として持つ
  (英語名の作品もあるので、日本語名が無いときは正式名をそのまま作品名にし、ローマ字名は None)
- `status` は `5 Volumes (Complete)` のような自由記述。先頭が `N Volumes` のときだけ巻数を取る(`0 Volumes` は不明として None)
- `genres` は少年・青年・ジョセイなど英語の区分を含む(`Shounen` `Josei`)。楽天ブックスを入れるまで、日本語のジャンル区分はここが代わりになる。`categories` は得票つきのタグで、得票 3 未満は捨てる(荒らし・誤りが混ざる)
- 原版元(`publishers` の `type = "Original"`)は**ローマ字名**(`Shueisha` `Overlap` `Kadokawa Shoten`)。あらすじ(`description`)も英語
- `year` は年だけ(文字列)。`type` は `Manga` `Manhwa` `Novel` `Doujinshi` など

## 使わない・後回しの取得元

| 取得元 | 理由 |
| --- | --- |
| openBD | API v1 の提供終了が告知されている |
| 楽天ブックス | ジャンル(少年・青年)・発売日が取れるが、API キー(アプリケーション ID)が要る。今は使わず、**取得元を差し込める形**(`SOURCE_CLASSES` への登録、`[metadata.keys]`、`SourceRequest.secret_params`)だけ用意した |
| メディア芸術データベース | 後回し |
| Web 小説系 API | 使わない(GOAL.md) |

## 実通信で確かめた応答(2026-11-02)

検索語 3 つを 3 取得元で引いた結果(記録は `tests/fixtures/metadata/`、再現は `scripts/metadata_probe.py`)。

| 検索語 | 国立国会図書館サーチ | AniList | MangaUpdates |
| --- | --- | --- | --- |
| お気楽領主の楽しい領地防衛 | 25 件中 10 件を取得。漫画(ガルドコミックス、青色まろ・赤池宗、オーバーラップ)と小説(OVERLAP NOVELS)の 1・2・3 巻、ISBN・発行年月つき。全巻の書誌 | 2 件(漫画 `Okiraku Ryoushu…`、小説)。ローマ字名・英題・別名・タグ・ジャンル | 漫画(全 8 巻、原版元 Overlap)と小説(全 10 巻)。ローマ字名・別名(英・スペイン・タイ語など)・ジャンル `Shounen`・タグ |
| かくかくしかじか | 作品名だけでは詩集・CD・映画ノベライズが混ざる。**著者 `東村アキコ` を付けると 1〜5 巻(集英社、ISBN つき)と映画ノベライズに絞れる** | 1 件目が本命(東村アキコ、全 5 巻、2011-09-28)。ローマ字名 `Kakukaku Shikajika` | 本命(全 5 巻、原版元 Shueisha、ローマ字名・各国語別名)。上位に `かくかくしこしこ` などの類似名 |
| Okiraku ryoshu no tanoshi ryochi | 当たる(読みから)。確からしさは 0.86(読みをローマ字にした `okiraku ryoushu…` との部分一致) | **0 件**(綴りが厳密) | 当たる。詳細から日本語名・ローマ字名・全 8 巻が取れる |

巻ごとの書誌(巻次・ISBN・出版者・発行年月)は国立国会図書館サーチだけが持つ。AniList・MangaUpdates は作品単位で、巻の情報は `total_volumes`(全何巻か)だけ。

## 覆すとしたら

- AniList の制限が 90 回/分に戻ったら、既定の間隔を 1.0 秒(≒ 60 回/分)まで下げてよい。変える前に公式ドキュメントの警告文が消えているかを見る
- MangaUpdates の制限が文書化されたら、既定の間隔をそれに合わせる。429 を実際に受けた記録が出たらここに数字を残す
- NDL サーチが検索の頻度を数値で示したら、それに合わせる
