# ブックマーク

作品か巻に付ける印(★)と、その一覧の画面(`#/bookmarks`)。利用者が付けた記録なので、蔵書レコード・読書位置と同じく消さない。

## 責務

- 作品・巻の印の付け外しと一覧(API は [[backend]] の表)。付け直しても付けた日時は変えない(冪等)
- 巻が整理で置き換わるとき・元に戻すときに印を移す。作品の統合で吸収先へ移す
- しないこと: 印を理由にした自動処理(名寄せの「手動が絡む」にも数えない。統合で吸収先へ移るだけで失われないため)

## 入口となるファイル

| パス | 役割 |
| --- | --- |
| `spinebox/bookmarks.py:97 list_bookmarks()` | 一覧。作品は `works._summary()` と同じ形、巻は作品名つき |
| `spinebox/bookmarks.py:85 transfer_volume()` | 整理での引き継ぎ。`spinebox/organize/organizer.py:1701 transfer_volume_state()`(読書位置・作品の割り当て・巻の書誌と同じ場所)から呼ぶ |
| `spinebox/works.py:379 _merge_bookmarks()` | 統合で吸収先へ移す(`merge_works()` から) |
| `spinebox/db.py:40 MIGRATIONS` | 版 12 の `bookmarks`。作品か巻のどちらか一方(CHECK)、それぞれ部分一意索引で 1 つにつき 1 行 |
| `frontend/src/bookmarks/BookmarkButton.tsx:8 BookmarkButton()` | 付け外しのボタン。巻の一覧・作品ページ(作品と各巻)・リーダー / 小説リーダーのメニューに置く |
| `frontend/src/bookmarks/Bookmarks.tsx:86 Bookmarks()` | 一覧の画面。入口は `frontend/src/route.ts:114 bookmarksHref` |

## 決めたこと

- **整理での引き継ぎは「写す」ではなく「移す」。** 読書位置は写す(元の巻にも残る)が、印を写すと、整理の後で新しい巻から外した印が
  元に戻したときに元の巻で復活する。移すなら元に戻した後の状態が「整理後に最後に決めた状態」と一致する。付けた日時は移しても変えない
- **受け入れ(`kind="intake"`)を元に戻しても印は写し戻さない。** 読書位置と同じく `_record_undone` が写し戻さないため、
  書庫で付けた印は missing になった巻に残る(行は消えず、一覧に出ないだけ)。受け入れフォルダの巻は一覧に出ないので、そこへ戻しても見えない
- **改名・移動は巻 id を変えないので、何もしなくても印はそのまま**([[organize]])
- **統合で両方に印があれば、早い方の日時で 1 つにする。** 統合された作品の id で付け外しすると吸収先が対象になる(`works.root_of()`)
- **一覧に出す巻の条件は `LISTED_VOLUMES_WHERE` と少し違う。** 「中の巻に分解済みの親」も出す。分解は開いたついでに起きるので
  ([[volume-split]])、分解の前に付けた印が一覧から黙って消えないようにするため(親はそのまま開ける)。
  オフラインの巻は `offline: true` で出し(読めないのでリーダーへのリンクにしない)、オフラインのままでも付け外しできる(ファイルを開かない)。
  整理で置き換わった元の巻・missing・受け入れフォルダ・設定から外したルートの巻は出さない(行は残す)
- **作品名順の並び:** 作品の印と巻の印を混ぜ、巻は巻の作品名で並べる。同じ作品の中では作品の印を先に、巻は巻番号 → 名前の順
- **一覧の画面で外した行は開き直すまで残す。** 押し間違えをその場で付け直せるようにするため(付け直すと日時は新しくなる)
- **入口:** サイドバー(#85)の「ブックマーク」(`bookmarksHref`)。サイドバーが入るまで置いていた、一覧の「作品 / 巻」の切り替え(`ViewTabs()`)の「☆ ブックマーク」は外した
