# 画面(UI)の作成・変更

> `CLAUDE.md` の「画面(UI)の作成・変更」節の写し。規約を変えるときは同じ PR でここも直す
> (片方だけ直すと食い違う)。手順は `.agent/skills/dads-ui/SKILL.md`。

- **`frontend/` の画面を作る・直すときは、DADS(デジタル庁デザインシステムβ版 v2.18.2)準拠とする。**
  スキル機構の有無にかかわらず、着手前に `.agent/skills/dads-ui/SKILL.md` と `references/`
  (tokens / components / checklist)を読む。
- 準拠の意味は見た目の流用ではなく、**値・構造・振る舞い**(コントラスト、ターゲットサイズ、
  フォーカスリング、ARIA、読み上げ順)を仕様に合わせること。
- 既存画面は**触る範囲だけ**準拠に寄せる。全画面の一括塗り替えはしない。
