# 検証チェックリスト

## 0. 実装の前に

- [ ] DADS のバージョンを確認した(トップページが v2.18.2 か。違えば一次情報を優先)
- [ ] 対象コンポーネントの「使い方」と「アクセシビリティ」を読んだ(概要だけにしていない)
- [ ] 割り当てた slug を決め、DADS にない UI はその理由を書いた

## 1. 機械的に見る

```powershell
cd frontend
npm test          # vitest
npm run build     # tsc --noEmit + vite build
```

DADS が禁じている書き方が残っていないか:

```powershell
Get-ChildItem frontend/src -Recurse -Include *.tsx,*.css |
  Select-String -Pattern 'placeholder=|maxLength=|tabIndex=\{?[1-9]|aria-live|outline:\s*none|disabled=\{true\}'
```

- `placeholder` をラベル代わりにしていないか(補助としての placeholder は可)
- `maxLength` で入力を制限していないか
- 正の `tabIndex` でフォーカス順を変えていないか
- エラーテキストに `aria-live` を付けていないか
- `outline: none` でフォーカスリングを消していないか

## 2. ブラウザ(必須)

`cd frontend; npm run dev`(API なしでよければ `npm run dev:mock`)。

- [ ] **375px** で横スクロールが出ない(`document.documentElement.scrollWidth <= window.innerWidth`)
- [ ] 768px(境界の両側)でレイアウトが切り替わる
- [ ] 1280px で間延びしない(本文の行長が長すぎない)
- [ ] ライト/ダークの両方で文字・境界・フォーカスが見える
- [ ] ブラウザのズーム 200% で操作できる
- [ ] `prefers-reduced-motion: reduce` でアニメーションが止まる
- [ ] `forced-colors: active` で境界と状態が分かる

## 3. キーボード

- [ ] Tab だけで主要な操作に到達できる(マウス専用の操作がない)
- [ ] フォーカスリングが見える(黒 4px + 黄 2px)
- [ ] フォーカス順が視覚順と一致する
- [ ] モーダル・引き出しは Esc で閉じ、閉じたあと元の要素へフォーカスが戻る
- [ ] モーダル表示中は背後の要素へフォーカスが移らない
- [ ] タブは矢印キーで移動できる(実装した場合)

## 4. コントラスト

| 対象 | 要件 | このリポジトリでの注意 |
| --- | --- | --- |
| 本文・ラベル | 4.5:1 | `--fg` / `--muted` は満たす。`--accent` は白背景で 4.75:1 |
| 補助文字 | 4.5:1 | 14px でも同じ。gray-500 `#7f7f7f` は 4.0:1 で不足 |
| 入力欄・チェックボックスの枠 | 3:1 | `--border`(1.27:1)を使わない。gray-600 `#666666` |
| アイコン・区切り線 | 3:1 | 同上。ダークは `#6b6b75` 以上 |
| フォーカスリング | — | 黄 `#ffd43d` + 黒。変更しない |

## 5. フォーム

- [ ] すべての入力に `<label>`(placeholder のみの欄がない)
- [ ] 必須/任意がラベルに書かれている
- [ ] サポートテキストとエラーテキストが入力に関連づいている(`aria-describedby`)
- [ ] エラー時は `aria-invalid="true"` で、枠が赤くなる
- [ ] 送信ボタンを `disabled` で塞いでいない(押した後にエラーを案内する)
- [ ] コピー&ペーストできる
- [ ] 入力値で予期しない画面遷移・送信が起きない

## 6. 構造・読み上げ

- [ ] `h1` が 1 つ、見出しレベルが飛んでいない
- [ ] ランドマーク(`header` / `nav` / `main` / `footer`)が適切
- [ ] テーブルに `th scope` があり、キャプションか見出しで何の表か分かる
- [ ] 画像に `alt`(装飾画像は `alt=""`)
- [ ] リンクテキストだけで行き先が分かる(「こちら」「詳細」だけにしていない)
- [ ] アイコンだけのボタンに `aria-label`

- [ ] 検証した幅・テーマ・操作を報告に書いた
- [ ] DADS から外した値・独自 UI の理由を書いた
- [ ] スコープ外の問題を見つけたら Issue に起票している(`file-issue`)
